# FlowerPainter 花卉

**当前为预览版。新保存的存档会携带花丛和旗帜模型；接收者需安装本模组 0.1.3 或更新版本。旧存档须先在原电脑安装新版、打开并重新保存，才能携带原有花丛模型。禁用或卸载模组后，自定义花丛不保证能恢复显示。**

把小花种成曲线、花毯、独立分区和旗帜。近景由密集的立体花头组成，远景使用简化立体花头；花朵合并为花丛块，避免每朵花都成为单独的游戏物件。

## 可以做什么

- 整片填充：流线拼色、花岛拼色。
- 独立分区：用圆、心形、花瓣或自由曲线划分区域，每块分别设置花色和填充样式，未填的区域保持空白。
- 曲线组合：绘制和编辑自由曲线，曲线用花与背景填充分别设置。
- 图片种花：导入 PNG、JPEG、BMP、GIF、TIFF、ICO、EMF、WMF 图片，用最接近的花色拼成小花图案，透明部分留空；动图使用第一帧。
- 花卉旗帜：271 个国家、地区、组织及主题模板，支持中文、英文和代码搜索。

## 开始使用

1. 点击花卉按钮，或按 **Ctrl+Shift+F** 打开工具。
2. 花毯、曲线和分区：先选择区域，再进入“设计”设置。
3. 旗帜：直接进入“设计 → 旗帜”，选择模板后点击“直接放置旗帜”，再点击地面。无需先画选框。
4. 图片：进入“设计 → 图片种花”，导入图片后点击“放置图片花丛”，再点击地面。已有选区会以中心为基准适配图片比例。
5. 放置后，按住旗帜或图片花丛拖动调整位置，松手确定；右键或 Esc 取消这次拖动。旋转和宽度使用滑杆，高度按模板比例自动计算。
6. 查看预览，确认后建造。已建造的项目可通过编辑重新调整。

## 外观与性能

“立体花密度”有 1–4 档，默认 4 档。数值越高，实际花头越多；“花头间距”和“花丛高度”分别控制花头尺寸与高度。“立体花显示距离”越高，细节保留到越远处，也会增加渲染开销。

大面积、密集花丛首次准备模型需要时间。细小文字和复杂徽章受花头间距与旗帜尺寸限制；远景仍可能看见规则排列纹理。本版不沿用旧贴图底面版本的“减少 99% 三角面”性能数字。

默认使用立体连片花丛，也保留普通花卉物件模式。连片模式按所选花卉对应的颜色生成统一花头，不保留所选物件原有的盆、边框或完整植物形态。

图片按最多 1024 像素的长边自动采样，不限制你选择原图的分辨率；颜色匹配当前 12 种花色，不能完全还原照片色调。图片的采样数据保存在设计中，删除原图后仍可编辑；含图片的存档需 0.1.4 或更新版本。

## 兼容与保存

- 无需安装 Placemaker 或第三方花卉资产包。
- 支持英语与简体中文，其余语言目前回退到英语。
- 升级不会自动替换已有花丛；需要编辑并重新建造才会采用新版几何。
- 新存档包含所用的花丛模型，另在游戏用户目录 `ImportedData/FlowerPainter/Patches` 保留本机缓存。已用清除测试模型缓存的方式验证恢复，尚未在第二台电脑上实测。旧存档重新保存前仍依赖原电脑缓存。
- 存档携带的花丛模型有 512 MB 上限；超过时无法保证跨电脑恢复，保存日志会记录错误。大型花丛会增加存档体积和读写时间。
- 卸载后再读档和真实第二台电脑上的读档仍待验证；分享前建议保留原始存档及本机缓存备份。
